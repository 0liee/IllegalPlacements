# IllegalPlacements

**Lightweight Minecraft plugin** that allows you to place blocks, plants, buttons and more in locations where it's normally impossible.

## Supported Versions

- Spigot / Paper **1.16+**

## Commands

- `/illegalplacements reload` - reload plugin configuration
- `/illegalplacements toggle` - enable/disable illegal placing

## Permissions

- `illegalplacements.reload` - allows reloading plugin
- `illegalplacements.use` - allows to placing blocks in illegal locations
- `illegalplacements.*` - all permissions

## Building

- `mvn clean package`
- requires java 11+
